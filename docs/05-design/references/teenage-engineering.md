# teenage engineering — the rules, as Refero records them

Source: <https://styles.refero.design/style/aecf9dda-5cba-4dc7-9e73-59b65d895cdf>, read 2026-09-22.

**Register.** A five-neutral monochrome catalogue: near-white canvas `#f6f8f7`, ink
`#000000`, a near-black band `#0f0e12` "with a barely-perceptible violet cast", hairline
greys `#e5e5e5` and `#b2b2b2`.

**Shape.** `border-radius: 0` on every component — "sharp edges are non-negotiable, they
are what makes the system feel industrial"; "any rounding breaks the industrial register".

**Elevation.** None. "No drop shadows, glows, or inset shadows." Depth is "the tonal jump"
from canvas to the dark band, and structure is 1px hairline rules that organise the page
into ruled bands.

**Colour.** "Never use color as decoration." The only chromatic element is an amber warning
triangle, which "earns its presence by being the sole exception"; a sixth colour is allowed
only for state (warning, error).

**Grid.** A three-column catalogue: cells separated by **vertical 1px rules** with 22px
gutters, content edge to edge, no card boxes.

**Type.** A hairline face at weight 100 for 13px body copy and 300 for headings; letter
spacing normal; body never centred — "technical-document reading rhythm".

**Rhythm.** Two spacing values carry the page: 15px element gap, 66px section gap.
