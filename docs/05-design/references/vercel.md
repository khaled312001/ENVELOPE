# Vercel — the rules, as Refero records them

Source: <https://styles.refero.design/style/f24daf3a-d43f-4dec-85a9-8ac1d5148a03>, read 2026-09-22.

**Register.** "A developer terminal rendered in print": a near-white canvas `#fafafa`, a
grey ladder from `#ebebeb` to `#171717`, and one chromatic text accent (a green,
`#297a3a`). Surfaces stack by tone (`#fafafa → #ebebeb → #171717`), not by shadow.

**Primary action.** A **filled near-black button** — `#171717` ground, white label — is
"the strongest visual weight in the system". Secondary actions are a transparent button
with a 1px hairline edge, "present but not competing". Chromatic colour is not spent on
buttons.

**Labels.** Mono, 11–12px, uppercase, `0.071em` tracking, for eyebrows, metadata and tags —
"Geist Mono owns that space"; the sans face is never used for labels.

**Elevation.** Hairline rings built from stacked box-shadows (`0 0 0 1px rgba(0,0,0,.08),
0 0 0 2px #fafafa`); "never drop-shadow".

**Shape.** 6px on cards and buttons, 9999px only for pills.

**Display type.** 56–64px, weight 400–450, tracking about `-0.06em`, line height 1.0.

**Grid.** A 4px base; compact density; 96–128px between sections, with no background shift
or divider between them.
