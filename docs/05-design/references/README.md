# Design references

Three systems from [Refero Styles](https://styles.refero.design/), read on 2026-09-22 as
**references, not templates** — Refero's own guidance, and this repository's rule against
imitating a real organisation. What was taken from each, and what was refused, is argued
in [`../direction.md`](../direction.md). These notes record only the *rules* each system
states, in enough detail to check a claim in `direction.md` against its source. No logo,
wordmark, typeface file, illustration or brand colour of any of them is used in the
product.
